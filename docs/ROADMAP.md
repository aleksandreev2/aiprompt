# Roadmap

## v0.1 — Gradio MVP
- LM Studio connection status and model discovery.
- Free-form intent input.
- Three compiler modes.
- JSON-schema constrained prompt planning.
- Verified-tag validation.
- Base / character / UC outputs with copy buttons.
- Validation, verified-tag and prose-fallback panels.
- Offline-first Windows launcher.
- Low-load inference guards and truncation retry.

## v0.2 — Prompt intelligence
- Alias and normalization tables.
- Hard/soft conflict checks in deterministic code.
- Prompt budget estimation.
- Minimal Patch `/fix` workflow.
- Editable structured prompt blocks.
- Better Russian→tag retrieval without dumping vocabulary into model context.

## v0.3 — Workflow UX
- Saved character cards.
- Presets and reusable scene/style profiles.
- Local history with seed/result notes.
- One-click regenerate only a selected block.
- Optional reference image analysis module.

## v0.4 — Knowledge sync
- Export/update script for curated Google Drive sources.
- Provenance manifest and freshness dates.
- Incremental tag database promotion.

## v0.5 — Desktop
- Optional Tauri packaging for Windows.
- One-click LM Studio health/model selector.
- Portable configuration and launcher.
